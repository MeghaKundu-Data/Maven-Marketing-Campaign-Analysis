# 📖 Data Dictionary — Maven Marketing Campaign Analysis

This document serves as the structural reference map for the tables and attributes used inside the Power BI data model. It defines the schema, data types, and business logic for all fields.

---

## 👥 Customer Demographics & Attributes

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| **ID** | Integer | Unique identification code assigned to each individual customer profile. |
| **Year_Birth** | Integer | The birth year of the customer (used to derive active customer age groups). |
| **Education** | Text | The highest level of academic qualification attained by the customer. |
| **Marital_Status** | Text | The social relationship status profile of the customer. |
| **Income** | Decimal | Annual gross household income generated by the customer. |
| **Kidhome** | Integer | Total number of small children residing within the customer's household. |
| **Teenhome** | Integer | Total number of teenagers residing within the customer's household. |
| **Dt_Customer** | Date | The date the customer originally enrolled or registered with the company. |
| **Recency** | Integer | Number of days elapsed since the customer's last recorded purchase transaction. |
| **Complain** | Boolean | Binary flag indicating if the customer filed a formal complaint in the last 2 years (1 = Yes, 0 = No). |

## 🍷 Product Spending Categories

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| **MntWines** | Decimal | Total financial amount spent on Wine products over the last 2 years. |
| **MntFruits** | Decimal | Total financial amount spent on Fruit products over the last 2 years. |
| **MntMeatProducts** | Decimal | Total financial amount spent on Meat products over the last 2 years. |
| **MntFishProducts** | Decimal | Total financial amount spent on Fish products over the last 2 years. |
| **MntSweetProducts** | Decimal | Total financial amount spent on Sweet confectionery products over the last 2 years. |
| **MntGoldProds** | Decimal | Total financial amount spent on Gold luxury items or specialty products over the last 2 years. |

---

## 🏬 Procurement & Purchasing Channels

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| **NumDealsPurchases** | Integer | Total number of bargain transactions completed using a discount code or active promotion. |
| **NumWebPurchases** | Integer | Total count of successful transactions placed natively through the company's website. |
| **NumCatalogPurchases** | Integer | Total count of items bought using the print mail-order catalog system. |
| **NumStorePurchases** | Integer | Total count of transactions completed directly inside physical brick-and-mortar store locations. |
| **NumWebVisitsMonth** | Integer | Aggregate number of times the user logged onto the digital website channel over the past month. |

---

## 🎯 Marketing Campaign Conversion Metrics

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| **AcceptedCmp1** | Boolean | Indicates if the customer accepted the offer extended during Marketing Campaign 1 (1 = Yes, 0 = No). |
| **AcceptedCmp2** | Boolean | Indicates if the customer accepted the offer extended during Marketing Campaign 2 (1 = Yes, 0 = No). |
| **AcceptedCmp3** | Boolean | Indicates if the customer accepted the offer extended during Marketing Campaign 3 (1 = Yes, 0 = No). |
| **AcceptedCmp4** | Boolean | Indicates if the customer accepted the offer extended during Marketing Campaign 4 (1 = Yes, 0 = No). |
| **AcceptedCmp5** | Boolean | Indicates if the customer accepted the offer extended during Marketing Campaign 5 (1 = Yes, 0 = No). |
| **Response** | Boolean | Target evaluation field indicating if the customer converted during the final promotional push (1 = Yes, 0 = No). |
